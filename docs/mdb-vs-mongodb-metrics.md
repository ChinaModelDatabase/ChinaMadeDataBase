# MDB 与 MongoDB 指标对比

日期：2026-10-03 | 基线：MongoDB 8.0
范围：代码规模、测试覆盖、功能完整性、性能指标、资源消耗

---

## 摘要

本文档从多个维度对比 MDB 与 MongoDB 的关键指标，帮助了解两者的能力差异。

**总体评价**：
- MDB 在**功能完整性**方面已达到 MongoDB 8.0 的 85%+
- MDB 在**代码质量**方面表现优秀（全 unsafe 禁止、1,700+ 测试）
- MDB 在**性能**方面各有优势（写入更快，读取略慢）
- MongoDB 在**生态成熟度**和**生产验证**方面领先

## 9. 总结

### 9.1 MDB 优势

| 维度 | 优势 |
|------|------|
| **安全性** | 全 unsafe 禁止，Rust 内存安全 |
| **性能** | 顺序写入更快，内存占用更低 |
| **国密** | 支持 SM2/SM3/SM4/TLCP |
| **代码质量** | 1,700+ 测试，代码结构清晰 |
| **依赖管理** | 外部依赖少，可审计性强 |

### 9.2 MongoDB 优势

| 维度 | 优势 |
|------|------|
| **功能完整性** | 支持更多查询特性、索引类型 |
| **生产验证** | 大规模生产环境验证 |
| **生态系统** | 丰富的驱动、工具、社区 |
| **并发性能** | 更细的锁粒度，更好的并发 |
| **运维能力** | 更成熟的运维工具和监控 |

### 9.3 适用场景

| 场景 | 推荐 | 原因 |
|------|------|------|
| **高吞吐写入** | MDB | LSM 顺序写优势 |
| **低延迟读取** | MongoDB | B+Tree 点查更快 |
| **内存敏感** | MDB | 内存占用更低 |
| **国密合规** | MDB | 支持 SM2/SM3/SM4 |
| **大规模部署** | MongoDB | 更成熟的运维能力 |
| **复杂查询** | MongoDB | 更成熟的查询优化器 |
| **开发测试** | MDB | 更轻量，启动更快 |
| **生产环境** | MongoDB | 更多生产验证 |

**注意**：以上为架构层面的对比分析，实际性能取决于具体工作负载、硬件配置和数据特征。建议进行实际基准测试以获得准确数据。
